Labels & inputs ⇒ წარწერები და შეყვანის ველები
Match label for with input id. Use useful types, names and native constraints. ⇒ label-ის for ველის id-ს დაუკავშირე. გამოიყენე შესაბამისი ტიპი, name და ჩაშენებული შეზღუდვები.
Validation & instructions ⇒ ვალიდაცია და მითითებები
Connect additional instructions with aria-describedby. minlength counts text length. ⇒ დამატებითი მითითება aria-describedby-ით დააკავშირე. minlength ტექსტის მინიმალურ სიგრძეს ადგენს.
Metadata & viewport ⇒ მეტამონაცემები და ხილული არე
Titles describe tabs. Descriptions summarize content. Device-width metadata enables responsive rendering. ⇒ title ჩანართს ასახელებს, description შინაარსს აჯამებს. device-width ადაპტირებად ჩვენებას უწყობს ხელს.
Selectors & cascade ⇒ სელექტორები და კასკადი
Selectors choose elements. A class is more specific than a type selector in ordinary author styles. ⇒ სელექტორი ელემენტს ირჩევს. ჩვეულებრივ სტილებში კლასის სელექტორი ელემენტისაზე უფრო სპეციფიკურია.
Readable typography ⇒ წაკითხვადი ტექსტი
A unitless line height scales with font size. A system stack needs no downloaded font. ⇒ ერთეულის გარეშე line-height შრიფტის ზომასთან ერთად იცვლება. სისტემურ შრიფტს გადმოწერა არ სჭირდება.
The box model ⇒ ბლოკური მოდელი
Padding is inside the border; margin is outside. border-box includes border and padding in width. ⇒ padding ჩარჩოს შიგნითაა, margin — გარეთ. border-box სიგანეში ჩარჩოსა და padding-საც ითვლის.
Use a parent’s flex layout for one-dimensional rows or columns. Wrapping prevents overcrowding. ⇒ ერთგანზომილებიანი მწკრივის ან სვეტის შესაქმნელად მშობელზე Flexbox ჩართე. გადატანა გადატვირთულ განლაგებას აგარიდებს.
Grid handles rows and columns. fr distributes available space among tracks. ⇒ Grid მწკრივებსა და სვეტებს მართავს. fr თავისუფალ სივრცეს მათ შორის ანაწილებს.
Media queries ⇒ მედიამოთხოვნები
Start with a narrow layout. Add columns when the viewport has room. ⇒ დაიწყე ვიწრო განლაგებით. სვეტები მაშინ დაამატე, როცა ეკრანზე ადგილი გაჩნდება.
Focus & reduced motion ⇒ ფოკუსი და შემცირებული მოძრაობა
Provide a visible focus ring. Respect motion preferences instead of making feedback depend on animation. ⇒ ფოკუსს ხილული ჩარჩო მიეცი. უკუკავშირი მხოლოდ ანიმაციაზე არ ააგო და მოძრაობის პარამეტრები გაითვალისწინე.
Custom properties ⇒ მორგებული CSS თვისებები
Give shared design values names. Use var() to read them across rules. ⇒ საერთო დიზაინის მნიშვნელობებს სახელები მიეცი და წესებში var()-ით გამოიყენე.
Variables & types ⇒ ცვლადები და ტიპები
Use const unless reassigning. Numbers, strings and booleans have different behavior. ⇒ თუ ხელახლა მინიჭება არ გჭირდება, const გამოიყენე. რიცხვებს, სტრიქონებსა და ლოგიკურ მნიშვნელობებს განსხვავებული ქცევა აქვს.
Functions & returns ⇒ ფუნქციები და შედეგები
Parameters are input names. A returned value can be used by the caller. ⇒ პარამეტრები შემომავალი მონაცემების სახელებია. დაბრუნებულ მნიშვნელობას გამომძახებელი იყენებს.
Arrays, objects & loops ⇒ მასივები, ობიექტები და ციკლები
Arrays collect values; objects have named properties; for…of visits collection values. ⇒ მასივი მნიშვნელობებს აგროვებს, ობიექტს დასახელებული თვისებები აქვს, for…of კი კოლექციას გაივლის.
DOM selection ⇒ ელემენტების პოვნა DOM-ში
querySelector returns the first match or null. Check it before accessing properties. ⇒ querySelector პირველ შესაბამის ელემენტს ან null-ს აბრუნებს. თვისების გამოყენებამდე არსებობა გადაამოწმე.
Event listeners ⇒ მოვლენის დამმუშავებლები
Pass a handler function that can run when an event occurs. Native buttons already support keyboard clicks. ⇒ მიაწოდე ფუნქცია, რომელიც მოვლენისას შესრულდება. ნამდვილ ღილაკს კლავიატურით გააქტიურება უკვე შეუძლია.
Filtering with data attributes ⇒ ფილტრაცია data ატრიბუტებით
Read data-category through dataset.category and toggle hidden for nonmatching items. ⇒ data-category dataset.category-ით წაიკითხე და შეუსაბამო პუნქტებისთვის hidden შეცვალე.
Honest form feedback ⇒ ფორმის ზუსტი უკუკავშირი
preventDefault stops navigation. checkValidity verifies constraints but does not deliver anything. ⇒ preventDefault გადასვლას აჩერებს. checkValidity წესებს ამოწმებს, მაგრამ არაფერს აგზავნის.
Theme storage ⇒ რეჟიმის შენახვა
localStorage holds strings for an origin. Handle unavailable storage with try/catch. ⇒ localStorage საიტის მისამართისთვის სტრიქონებს ინახავს. მიუწვდომელი საცავი try/catch-ით დაამუშავე.
