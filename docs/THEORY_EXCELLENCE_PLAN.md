# Firstlight theory: completion plan

## Shipped in this update
- 22 deeper lessons across semantic HTML, document metadata, accessible forms, images, navigation, data tables; CSS layout, cascade, Flexbox, Grid, responsive design, motion; JavaScript values and scope, functions, arrays, DOM events, validation, UI state, async errors, browser storage, and safe DOM output.
- Each deep lesson includes a Georgian explanation, why the concept matters, annotated code, a pitfall, a guided experiment, hints, a short recall question, and editable HTML/CSS/JS files.
- The theory library presents the HTML → CSS → JavaScript → browser pipeline. Correct answers are remembered as theory mastery, separately from course completion and XP.
- Existing saved sandbox drafts remain valid; mastery merges between local and cloud progress.

### 4. Progress and discovery
- [x] Search and filter topics; persist mastery without changing course XP.

### 5. Accessibility and motion
- [ ] Verify keyboard-only navigation, focus visibility, screen-reader names, and contrast across all states.
- [ ] Honor reduced-motion preferences everywhere; use motion to explain state changes, never as decoration alone.
- [ ] Test zoom, large text, touch targets, and narrow mobile widths.
- [ ] Add captions/transcripts if video lessons are introduced.

### 6. AI tutor and safety
- [ ] Keep provider keys server-side; never place secrets in browser code or local storage.
- [ ] Provide Georgian explanations grounded in the current lesson and sandbox files.
- [ ] Offer explain, debug, hint, and review modes; ask before replacing a learner's code.
- [ ] Rate-limit requests, disclose data handling, and let learners clear chat history.

### 7. Quality and release
- [ ] Add content checks for broken links, invalid code, duplicate IDs, and untranslated strings.
- [ ] Add unit tests for progress validation/merge and browser checks for core learning journeys.
- [ ] Review performance, telemetry consent, error reporting, and privacy retention.
- [ ] Stage releases, verify production behavior, monitor errors, and keep a rollback path.
